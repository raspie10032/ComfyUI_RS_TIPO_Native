# Gemma 중간 출력의 문장 판별 제거 — 0.2.9

2026-11-05. 0.2.7에서 최종 태그의 문장 판별을 제거했지만, 중간 공동
계획에는 영어 문장 형태를 검사하는 코드가 남아 있었다. 모델이 유효한
JSON 안에 `blue eyes, white shirt` 같은 태그 목록이나 짧은 구절을 반환하면
태그 변환에 전달하기 전에 재시도하고, 재시도도 같은 형태면 중단했다.

이 검사를 제거했다. 비어 있지 않은 태그 목록, `Appearance:` 라벨,
짧은 구절, 한국어가 섞인 설명도 태그 변환에 그대로 전달한다. 자연어
출력을 선택하면 반환된 표현을 유지한다. 영어 문장으로 출력하도록 하는
모델 지시는 유지하지만, 지시를 따랐는지를 코드가 판정해 실패시키지 않는다.

문법 판별용 보조 함수와 그에 따른 필드 재작성 경로도 제거했다.
구조·원문 가중치·명시적 제외 조건 오류의 재시도는 보고된 오류만 고치며,
확장 작업을 다시 실행하거나 특정 문장 시작 표현을 강제하지 않는다.
JSON 문법 오류의 별도 복구 경로는 0.2.8의 동작을 유지한다.

유효한 JSON, 번호별 인물 슬롯과 문자열 자료형, 비어 있지 않은 인물 출력,
원문 가중치, 사용자가 지정한 제외 태그는 계속 확인한다. 영문 태그 원문
보존, 태그 중복 제거, 추가 태그 개수 제한, ComfyUI 네이티브 자원관리도
기존 동작을 유지한다. 모델과 의존성 변경은 없다.

## 재현 및 회귀 검사

수정 전에는 모델 응답을 고정한 검사에서 0·1·2·10인 태그 출력과
자연어 출력이 같은 문장 판별 오류로 실패했다. 수정 후에는 중간 응답을
다음 태그 변환의 입력으로 그대로 전달하며, 불필요한 재시도 없이 완료한다.
태그 변환이 추가한 새 표현은 유지하고, 동일 태그의 반복만 제거한다.
한국어 혼합·라벨·한 단어 출력과 빈 응답의 구조 검사도 구분해 확인한다.

Python 회귀 검사 164개와 JavaScript 검사 스크립트 4개를 통과했다.
기존 JSON 복구, 슬롯 오류, 원문 가중치, 명시적 제외 태그와 취소 처리를
검사하는 테스트도 통과했다.

## 실제 로컬 실행

ComfyUI 8188에서 서로 다른 시드의 텍스트 생성 32회를 연속 실행했고
32회 모두 완료했다. Q4 2·10인과 BF16 0·1·2·10인을 포함하며 태그·자연어,
한국어 입력과 가중치 묶음을 섞었다. 총 127회의 실제 모델 호출 중
1회는 기존 구조 검사 재시도를 사용했고, 문법 판별 실패는 없었다.
해당 연속 검사는 이미지나 유료 NAI 생성을 실행하지 않았다.

별도로 실제 오류 로그의 2인 응답을 다시 입력하여, 문법 재시도 없이
태그 변환에 전달되는지 확인했다. 이 재생 검사의 모델 호출은 고정 응답을
사용했으며, 위의 실제 GPU 연속 실행과 구분한다.

문장 품질, 번역의 완전성, 사실·역할의 정확성은 모델 출력의 한계로 남는다.
이 수정은 그런 품질 문제로 실행을 중단하던 동작을 제거한다.
